## Facebook

EvoMesh 0.4 closes the core architecture of our local-first multi-agent runtime. Work the mesh already knows how to do now runs as a typed procedure. It uses zero or one model call, and every effect is journaled so a crash never repeats a write. Before freezing it, we had it reviewed twice. The reviews found a child agent that ignored its model budget, crash recovery that silently undid an operator's cancel, and a fix marked "verified" only because other agents stayed busy. Each one got a failing test before its fix. Also new: an Idea Scout that proposes improvements, and nothing becomes work until you put a 👍 on it in Telegram.
